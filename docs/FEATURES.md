# Osmium Features

Osmium is an AI focused employee management workspace for HR teams, managers, and project leads. It brings employees, projects, leave, files, visual planning, and AI assistance into one product experience.

## Main Workflows

### 1. Start From the Dashboard

Managers can open Osmium and immediately see the most important signals: total employees, live projects, available people, active assignments, leave counts, completed projects, upcoming deadlines, and calendar activity.

### 2. Add and Manage Employees

Teams can create employee profiles with names, emails, roles, teams, ratings, experience, work hours, skills, availability, profile photos, and project assignments.

### 3. Plan and Track Projects

Project leads can create projects, assign managers and team leads, set timelines, track progress, list required skills, define roles, and assign team members.

### 4. Use Visual Planning

The canvas lets users place employees and projects on a visual workspace, connect them, inspect details, assign project roles, and use AI-assisted project staffing.

### 5. Track Leave and Availability

Leave records show who is away, when they are away, and how absences affect team capacity. The heatmap makes absence patterns easy to scan.

### 6. Ask AI Questions

The full AI assistant supports workspace conversations and document-based questions. The mini assistant appears across the app so users can ask quick questions about employees, projects, availability, absences, skills, and dashboard metrics.

## Navigation Map

- Dashboard: overview metrics, deadlines, calendar, quick actions, leave heatmap.
- Canvas: visual workspace for employees, projects, connections, and assignments.
- Org Tree: visual team structure and staffing insights.
- Employees: employee directory, filters, profile cards, create/edit/delete.
- Projects: project list, create/edit/delete, AI-assisted project fields.
- Files: upload, filter, download, and delete documents.
- AI Assistant: full chat experience with history and files.
- Leave: leave heatmap, active/upcoming leave records, add/delete leave.
- Settings: theme, canvas preferences, notifications, and cache clearing.

## Product Positioning

Osmium should feel like a calm workplace command center. The user should not need to understand technical details to understand the value.

Use friendly language:

- "team workspace" instead of technical access language.
- "files for this chat" instead of injected context.
- "workspace assistant" instead of RAG assistant.
- "syncing" instead of API connection status.
