# Project Management

The Projects page helps teams create, staff, and track active or upcoming initiatives.

## Project List

Projects are shown as cards with useful planning details such as:

- Project name
- Client name
- Status
- Progress
- Dates
- Required skills
- Assigned team members

## Add Project

The project form captures:

- Project name
- Client name
- Client email
- Start date
- End date
- Manager
- Team lead
- Status
- Progress percentage
- Description
- Required skills
- Roles needed
- Team members

## Status and Progress

Projects can be marked as:

- Active
- Planning
- On Hold
- Completed

Progress can be set from 0 to 100 percent so project cards and dashboard signals can reflect movement.

## Required Skills

Project leads can list the skills required for the project. These skills help clarify staffing needs and support AI-assisted matching.

## Roles Needed

Projects can include role requirements such as Designer, QA, Frontend Developer, Backend Developer, or other needed roles.

## AI-Assisted Project Fields

Osmium includes AI helpers inside the project form:

- Refine and summarize a project description
- Generate required skills
- Generate roles needed

These helpers reduce manual writing when a project is being created or updated.

## Team Assignment

Users can assign employees to a project while creating or editing it. The form supports:

- Manager selection
- Team lead selection
- Searchable member selection
- Assignment summary chips

Managers and team leads are kept separate from regular team member selection to avoid duplicate responsibilities.

## Edit and Delete Projects

Existing projects can be edited or deleted from the project cards. The app confirms destructive actions before removing project records.

## Project Draft Prompt

If a user closes a project form with unsaved details, Osmium shows a custom prompt to resume editing or close the draft.
