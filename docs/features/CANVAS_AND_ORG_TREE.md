# Canvas and Org Tree

Osmium includes visual tools for understanding how people, teams, and projects relate to each other.

## Canvas

The canvas is a visual planning surface for employees and projects. Users can place nodes, connect them, inspect details, and build project staffing views.

## Canvas Side Panel

The canvas side panel lists:

- Projects
- Employees

Users can click or drag items from the side panel onto the canvas.

## Canvas Controls

The canvas supports:

- Pan
- Zoom in and out
- Reset view
- Fit to screen
- Grid snapping
- Select and move nodes

Keyboard and pointer interactions make it useful for larger planning layouts.

## Employee Nodes

Employee nodes show employee identity and role information. Users can inspect employee details or connect an employee to a project.

## Project Nodes

Project nodes show project name, client, status, progress, connected team count, and quick actions.

## Connections

Users can connect project nodes to employee nodes. Connections represent project assignments and can carry roles such as:

- Manager
- Team Lead
- Member
- Pending

Connections can also be removed from the canvas.

## AI Project Assignment

Project nodes include an AI-assisted assignment action. It helps suggest and assign available employees based on project needs and team capacity.

## Inspector

The inspector panel shows details for selected employees or projects. It helps users view more information without leaving the canvas.

## Org Tree

The org tree shows team structure in a visual hierarchy. It helps managers understand reporting lines, root employees, assigned employees, and team layout.

## AI Org Lens

The org tree includes an AI-oriented lens for staffing insights. It can help highlight availability, overloaded managers, project staffing risks, and capacity signals.
