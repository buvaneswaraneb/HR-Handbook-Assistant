# Dashboard

The dashboard is the starting point for managers and HR teams. It summarizes team health, project movement, availability, and upcoming work in one place.

## Key Metrics

The dashboard shows high-level metrics:

- Total employees
- Live projects
- Available employees
- Active assignments
- Employees on leave
- Completed projects

These numbers help users understand the current workspace state without opening every page.

## Availability Overview

The available employee metric helps project leads quickly understand whether the team has capacity for new work.

## Active Assignments

Active assignments show how many people are currently connected to projects. This helps managers spot workload and staffing movement.

## Google Calendar

The dashboard includes a Google Calendar widget for upcoming events. Users can connect and sync calendar activity so important dates are visible near project and team information.

## Deadlines

The deadlines card highlights upcoming and critical project due dates. It helps users see which projects need attention soon.

## Quick Actions

The quick actions card lets users jump directly into common tasks:

- Add Employee
- New Project
- Open Canvas
- AI Assistant

## Leave Heatmap

The dashboard includes a compact leave heatmap so managers can see absence pressure without leaving the dashboard. A full leave view is available from the Leave page.

## Refresh

The dashboard can be refreshed manually to load the latest team, project, calendar, and leave information.
