# Settings and Preferences

The Settings panel lets users adjust the workspace experience without leaving the current page.

## Theme

Users can choose:

- Dark
- Light
- System

The System option follows the user's operating system preference.

## Canvas Preferences

Canvas settings control how the visual planning workspace behaves.

### Snap to Grid

Snap to Grid helps users keep canvas nodes aligned while arranging employees and projects.

### Edge Labels

Edge Labels control whether connection labels are shown on the canvas.

### Node Animation

Node Animation controls whether canvas nodes use animated effects.

## Reset Canvas Layout

Users can reset the canvas layout when they want to start arranging nodes again.

## Activity Notifications

Activity notifications can be enabled or disabled depending on how much feedback the user wants while working.

## Clear Local Cache

Clear Local Cache removes locally stored employee, project, and file data so the app reloads fresh information on the next view switch.

## Design Goal

Settings should feel simple and operational. The user should understand each option without needing technical knowledge.
