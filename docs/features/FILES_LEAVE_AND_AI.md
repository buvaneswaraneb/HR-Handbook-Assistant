# Files, Leave, and AI

Osmium combines supporting workflows for documents, absence planning, and AI assistance.

## Files

The Files page lets users upload and manage documents, assets, and resources.

### Uploads

Users can upload files by dragging and dropping or browsing from the upload area. The upload form supports:

- Selected file preview
- Department
- Optional description

### File Filters

Files can be filtered by:

- All files
- Engineering
- Design
- HR

### File Actions

Users can:

- View file information
- Download files
- Delete files

## Leave Management

The Leave page tracks employee absences and resource availability.

### Add Leave

Users can add leave for:

- An employee selected from the system
- A manually entered employee name

Leave records include:

- Start date
- End date
- Leave type

Supported leave types are Annual Leave, Sick Leave, and Unpaid Leave.

### Leave Heatmap

The leave heatmap shows absence patterns across the year. It helps managers understand when multiple people are away and where capacity may be affected.

### Active and Upcoming Leave

The leave list shows current and future leave records with employee name, dates, duration, and leave type.

### Delete Leave

Leave records can be deleted after confirmation.

## Full AI Assistant

The AI Assistant page is a full chat workspace for HR and project questions.

### Chat

Users can ask questions about employees, projects, documents, and workspace knowledge.

### Files for This Chat

Users can attach documents and ask questions about them inside the chat.

### Chat History

The AI page includes conversation history. Users can:

- View previous conversations
- Reopen a previous conversation
- Continue a conversation
- Delete a conversation
- Start a new chat

## Mini Workspace AI

The mini assistant is a floating assistant available across the app except on the full AI page.

### Quick Questions

The mini assistant is designed for fast questions about:

- Available employees
- Absentees today
- Critical projects
- Dashboard summary
- Skills
- Deadlines
- Assignments

### Workspace-Aware Answers

The assistant uses workspace information such as employees, projects, leave records, activity, and dashboard totals. It stores a short-lived local snapshot so repeated questions can be answered faster.

### Thinking State

When the mini assistant is thinking, the page edge shows an animated glow. This gives users feedback without covering the page content.
