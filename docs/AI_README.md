# Osmium AI

Osmium includes AI tools that help users ask questions about employees, projects, leave, files, and dashboard information.

## AI Assistant Page

The full AI Assistant page is used for longer conversations.

Users can:

- Ask questions about employees and projects.
- Attach files and ask questions about those documents.
- View previous chat history.
- Continue old conversations.
- Start a new chat.
- Delete old conversations.

Example questions:

- Who is available for a new React project?
- Which projects have critical deadlines?
- Summarize this document.
- What skills do we have in the team?

## Mini Workspace AI

The mini AI assistant is a floating chat window available on most pages.

It is useful for quick questions while working in the app.

Users can ask about:

- Available employees
- Absentees today
- Project deadlines
- Critical projects
- Skills
- Assignments
- Dashboard summary

Example questions:

- Who is available right now?
- Who is absent today?
- Which projects are due soon?
- Give me a dashboard summary.

## Workspace Context

The mini AI uses workspace information such as:

- Employees
- Projects
- Leave records
- Dashboard totals
- Recent activity

This helps it answer questions with the current team and project data.

## Thinking Glow

When the mini AI is thinking, the page border glows to show that AI is working.

## Goal

The AI should feel like a helpful workplace assistant. It should answer in simple language and focus on employees, projects, leave, files, and team availability.
